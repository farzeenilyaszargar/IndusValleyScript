# Opaque derived comparison samples

These files preserve numeric token identity, adjacency, source-document metadata and sampled offsets. They omit token-to-text dictionaries, translations and complete original documents. Dictionaries remain in the local acquisition cache for source auditing. The transformations are described in scripts/language_compare.py and docs/EXPERIMENT_004.md. Source hashes, URLs and revisions are recorded in manifest.json.

Tamil sources: Sentamizh Corpus, indic-corpora, curated by Revathi Prasad with classical-Tamil annotation by Vijayalakshmi Prasad; selected original-text fields derive from Project Madurai editions. Upstream declares Apache License 2.0: https://www.apache.org/licenses/LICENSE-2.0. The pinned license file URL and hash are in the manifest. Changes: Unicode normalization, removal of punctuation/formatting, opaque integer recoding and seeded contiguous-window sampling. No translation or interpretive annotation is included. Exact Akananuru edition metadata is incomplete, as documented in LANGUAGE_RESOURCES.md.

Vedic Sanskrit sources: UD_Sanskrit-Vedic, authors/annotators Oliver Hellwig, Salvatore Scarlata, Elia Ackermann, Paul Widmer, Erica Biagetti and Sven Sellmer. See upstream README and the cited Vedic treebank publications. Upstream and the derived Vedic numeric sample files are licensed under Creative Commons Attribution-ShareAlike 4.0 International: https://creativecommons.org/licenses/by-sa/4.0/. Source repository: https://github.com/UniversalDependencies/UD_Sanskrit-Vedic. Changes: CoNLL-U integer-ID FORM extraction, punctuation exclusion, Unicode normalization, opaque integer recoding and seeded contiguous-window sampling. No linguistic annotation is used to supply Indus values.

These licenses apply to their respective derived data; they do not assign an unrestricted license to all code or other corpora in this repository. Numeric samples are sufficient to recompute distributional metrics without reconstructing candidate-language text. To regenerate sampling from original resources, reacquire pinned files and run the sampler; local dictionary and document audit are available after acquisition.
