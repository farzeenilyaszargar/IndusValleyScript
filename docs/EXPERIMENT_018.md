# Experiment 018: substitution on novel collapsed patterns

17 October 2026. Retrospective follow-up to Experiment017, whose aggregate test scores and collapse-overlap counts are already known. The previous turn made verified progress: release0.17 was pushed and its full reproduction passed GitHub CI. This design is recorded before inspecting the new subset scores. It is not a new independent blind corpus or an expansion of linguistic coverage.

Keep Experiment017's original full-ID exact/reverse split, training-only top32 sign vocabulary, target counts, five fitted training keys and frequency-rank baseline unchanged. Removing held-out rows must never alter the training vocabulary or refit training keys. For each proxy, re-evaluate those five keys on the retained validation subset and select the minimum validation loss, with the existing rounded12/index tie rule. Do not select using any test outcome. This isolates a change in evaluation population rather than optimizer budget.

Canonicalize each encoded string against its reverse, including every fixed UNK slot. Retain validation rows only if their collapsed pattern is absent from training. Retain test rows only if their collapsed pattern is absent from both training and retained validation. Retain repeated rows within one partition with their original weights; assign one bootstrap group per canonical collapsed pattern. Export every original split membership, source/encoded string, exclusion reason and retained subset size/coverage. Assert all three retained pattern sets are disjoint. Unknown slots retain their positions and edges.

Execute on Indus and the existing explicitly nonphonetic seed17 administrative control, for each of the Tamil/Vedic target models. Include the known artificial ciphers as positive diagnostics: their original grouped split already has no exact/reverse collapsed duplicates, so filtered results should reproduce the previous calibration. Reconstruct scores from the hash-verified frozen target inputs and stored keys, independently checking stored training losses before reuse.

Report retained-validation selected restart, frequency/selected test bits per original token, gain, per-text losses and coverage. Bootstrap canonical collapsed test groups5,000 times (seed20261017), weighting tokens within each sampled group. Report percentile95% intervals and98.75% intervals as a four-comparison Bonferroni sensitivity for two proxies times Indus/nonphonetic. Small-group and corpus-conditional uncertainty remains; no universal significance or causal effect of leakage removal follows. Also report score/gain for the original selected key on the same retained test subset, to distinguish validation reselection from population change.

A surviving gain cannot validate a phonetic reading, given the negative control, weak restart agreement,32-unit restriction, proxy chronology/genre and unknown collapse. Loss differences across proxies cannot select a language family. No real Indus translation, sound value or sign equivalence is adopted. This narrows one known evaluation weakness while keeping exhaustive acquisition and genuine decipherment open.
