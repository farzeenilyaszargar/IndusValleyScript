# Experiment 015: reference-number candidates and original photograph audit

17 October 2026. Source exploration inspected the CISI 1 data table and an M-1 pilot. The source explicitly warns that Finnish concordance (FC) numbers and Mahadevan numbers are not uniformly interchangeable. No numeric match is accepted as an independently verified object identity. This design is recorded before candidate-model fitting.

Transcribe the complete first Mohenjo-daro reference page (CISI 1 printed p.366; PDF page 402 in the cached scan): M-1 to M-100 and their literal FC numbers. Keep the page/hash, uncertain digits and pilot evidence. The references point to independent archaeological objects, but using their identical numeric FC/Mahadevan values is a candidate-generation rule only. Do not infer a site-name meaning or propagate a crosswalk from this rule.

For each M-#A transcription, generate a candidate only when its FC number identifies a unique otherwise eligible primary Mahadevan side-0/line-0 record and sequence lengths agree. Retain all rejections and raw references. Filter uncertainty using both primary annotations and existing Parpola eligibility. No supplied sign alias is used to choose, filter or align candidates. A pilot inspected M-1 and its source aliases before this design; force its whole connected duplicate group into training, never validation/test.

Group exact/reversed copies linked through either namespace. Split remaining groups using seed42 and 80/10/10 proportions by group count, keeping the M-1 pilot group in training. Select direct/reversed relative alignment using training mapping entropy only. Learn majority Parpola-to-Mahadevan ID correspondence; report held-out all-position accuracy, known-source coverage and full failure ledger. Review priority: at least three training positions, at least two candidate objects and >=90% purity. This measures reference-candidate consistency, not verified object matching or decipherment. Source-number coincidences, shared transcription ancestry, imperfect glyph equivalence and tiny holds limit inference.

Independently record original seal/face and impression photographs actually viewed, including mirror order, damaged/unseen areas, catalogue metadata and broad shape agreement. Distinguish this unblinded Codex-assisted reading from an expert transcription. Originals and impression labels A/a are not interchangeable without an explicit mirror transform. Do not redistribute the scans or claim to have reviewed photos not actually inspected. Report unresolved FC/Mahadevan identities rather than silently resolving them using sign aliases or desired model results.
