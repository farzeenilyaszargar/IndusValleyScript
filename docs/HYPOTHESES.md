# Hypotheses and tests still required

These are a research agenda, not completed decipherments. Thresholds below are proposed for future prospective experiments; they were not preregistered before the current exploratory analyses.

| Hypothesis | Current evidence | Required discriminating test |
|---|---|---|
| Local sequencing constraints | Held-out bigrams beat unigrams and independent positional slots | Repeat on independently photograph-verified corpus with mold/family grouping |
| Some stroke groups function as quantities | Tally-like/fish adjacency enrichment in a small clean CISI subset | Annotate stroke counts, object class, measured amounts and weights independently; test monotonic relationships |
| Fish signs express stars via Dravidian rebus | Published lexical proposal; adjacency alone is inconclusive | Independently identify particular asterisms or calendar context and predict unseen number/fish combinations with fixed values |
| Seal texts label names or titles | Positional and context classes | Independent proper-name anchor or securely bilingual seal; require shared sound values to generalize across unseen names |
| Administrative notation | Positional slot control predicts some signs but misses observed adjacency | Test richer transaction grammar against object classes and independently identified commodity quantities |
| Proto-Dravidian linguistic system | Not tested against comparable linguistic corpus | Licensed historical corpus; explicit reconstruction uncertainty; matched sign/grapheme units; held-out alignment beating random and competing-family baselines |
| Indo-Aryan or Austroasiatic system | Not tested against comparable linguistic corpus | Same protocol as above; no lexical cherry-picking or chronology assumed from later languages |
| Allographs conceal smaller inventory | Preserved source morphology and candidate contextual neighbours | Blind glyph review plus split/merge ablation; no adoption of speculative upstream canonical mappings |

## Decipherment acceptance criteria

1. Declare the sign inventory, reading direction, phonetic/logographic rules, and exceptions before testing.
2. Justify sound values through independent archaeological/linguistic evidence rather than fitted resemblance alone.
3. Translate previously unused inscriptions with consistent readings and constrained grammar.
4. Predict new observations (quantity, object class, bilingual value, or independently known name).
5. Compare to alternative mappings with equal complexity; quantify researcher flexibility.
6. Make transcriptions, code, negative cases, and uncertainty available for specialist review.

## Why an arbitrary configured language is not an answer

Any sign system can be renamed with invented syllables. We executed ten such relabelings; every one preserves entropy. The induced finite template grammar is an explicit formal description of sign arrangements. Neither procedure reconstructs a historical spoken language. Assigning a plausible-looking sentence to each seal would add unconstrained meanings, rather than recover them.
