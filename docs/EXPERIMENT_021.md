Construct a new known two-alias-per-full-unit cipher on those windows: alias permutation seed1031, variant choices seed2031, held-only units remain fixed source UNK. Split by the existing exact/reverse and transitive one-substitution components (length>=3), seed42,80/10/10% components. Truth is consulted only for this artificial-channel feasibility audit; no optimizer or Indus key is fitted in this experiment.

In particular, check the existing normalized channel's requirement that every target unit have an assigned observed training glyph. If true units are absent from the calibration training set, its true key cannot satisfy that requirement, even if there are enough glyph types in total. Record the failure rather than deleting rare units or inventing assignments. Preserving a full target inventory may require an emission model that allows unoccupied units and marginalizes unknown observations; that algorithm remains future work, not a result claimed here.
