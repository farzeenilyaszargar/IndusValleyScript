# Experiment 012: explicitly non-phonetic administrative control

Recorded before execution, 15 October 2026. The independent-slot control does not model conditional institutional/commodity conventions. Test a richer, fully specified fictional administrative notation for local predictability and shuffle rejection. This is a constructive compatibility test, not a likelihood ratio or classification of the real Indus system.

Literature motivation: selected construction, prediction, lexical-stress and limitations passages in Raghavendra's 2026 SIGIL preprint (arXiv:2608.02999v1). The canonical corpus was not located in the inspected article, its arXiv source archive, author's landing page or GitHub repository search. Record those failed retrievals; do not claim to reproduce SIGIL. Our generator is independently authored, with its own parameters and no borrowed signs or phonetic dictionary.

Fixed fictional inventory: 160 institutions, 96 guilds, 160 commodities, eight quantity emblems, four rank emblems and five validation emblems. Institution-to-guild licenses select six guilds, guild-to-commodity licenses select eight commodities, each by a separate seed before generation. Quantities draw from a commodity-specific preferred pair; ranks from a guild-specific preferred pair. Broad institution draws have fixed Zipf exponent 1.15. Templates comprise optional institution, optional two-sign office block (guild/rank), zero or more two-sign ledger entries (quantity/commodity), and optional validation emblem; sample eligible templates of the supplied length with fixed weights favoring shorter ledgers and present blocks. Every token has a stored semantic role/reference or explicit integer quantity/rank; no token has a phonetic value.

Generate three seeds (17,29,43), each with the exact 2,156 Indus length list (9,221 tokens). Length matching is the only empirical calibration; no Indus sign frequencies, transitions, fitted loss or model-selection results tune generation. Retain generated duplicate records and group exact/reversed copies before train/validation/test splitting. Split seed 42; select bigram smoothing by validation sequence loss, score EOS/collapsed UNK identically to the real benchmark. Compare unigram/bigram held-out bits and exact single-sign masks; use 99 within-text shuffles and the same conditional-entropy formula. Report actual inventory, duplicates and split sizes. Repeated generated instances are not independent archaeological samples, and these seeds are realizations of one architecture, not an ensemble of all plausible non-phonetic systems.

Export generator settings, licenses and full token-level semantic records. Verify exact length agreement, absence of phonetic values, deterministic generation and semantic-role constraints. If the artificial system also shows local dependence and masking gains, those features alone cannot require encoded speech; differences in magnitudes do not identify Indus meanings or language. No administrative semantic assignment is propagated to an Indus ID.
