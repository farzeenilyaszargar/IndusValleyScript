# Experiment 014: held-out prediction of field-symbol codes

Recorded before fitting/scoring, 15 October 2026. Ask whether sign presence improves prediction of the official recorded field-symbol code beyond site, object type and supplied text length. This can constrain semantic-domain hypotheses but cannot prove that a sign names a pictured entity. Use the Experiment 013 frozen primary snapshot; keep each original face/line and its own metadata together.

Start from all 2,391 strictly eligible single-line rows. Link rows sharing an object textnum or canonical exact/reversed sign string into connected components, including rows with no field symbol so that omitted faces cannot bridge train/test. Assign components using seed 42 and 80/10/10 proportions by component count. Then omit target codes 0 and 999 without remaking the split. These are declared literal exclusions, not a new iconographic classification. Report component sizes and actual row/class proportions; near-copy or mold families remain unresolved.

Target classes: exact field-symbol codes represented on at least 20 distinct training objects; every other code, including previously unseen test codes, becomes RARE. Never infer animal names from the secondary codebook. Define metadata stratum as broad source textnum site group, literal object-type code and length bin (1,2,3,4,5,6+). Baseline: class counts within stratum interpolated to add-0.5 pooled class priors; choose interpolation strength 1/5/20/100 by validation bits per row.

Freeze that chosen baseline strength. Add a training-only multinomial naive-Bayes sign likelihood with add-one smoothing over actual training glyph IDs. Use each distinct visible sign once, average its class log likelihood over distinct known signs, then add to baseline log probability with weight 0/0.25/0.5/1/2 selected on the same validation rows. Unseen signs supply no class evidence. Including weight zero permits no incremental effect; do not change the baseline smoothing to obtain a gain.

Primary score: held-out bits per archaeological row (not per glyph), compared with the frozen metadata baseline. Also report accuracy, macro class recall, class-wise confusion counts, unrepresented stratum/sign coverage, and majority-class accuracy. Bootstrap paired loss differences by the connected test component (1,000 resamples). Retain all duplicate object rows with declared weighting; intervals are conditional on this corpus/split and do not establish independent mold families. Export split identities, train-only target map, candidate weights/validation scores and every held-out class probability. No lexical, rebus, phonetic or animal-name assignment enters input or inference.
